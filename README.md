

# 🎮 Tetris Game (Built by Yasar)

This is a classic **Tetris game** built using **Python** and **Pygame**. The game includes all the basic Tetris mechanics: piece rotation, line clearing, scoring, and game over screen. It also displays the next piece preview and a score counter.

---

## 🧱 Features

- Classic Tetris block shapes
- Piece rotation
- Grid-based movement
- Line clearing and scoring
- "Next piece" preview
- Game over and restart functionality
- Simple, clean UI using Pygame

---

## 🛠️ Requirements

- Python 3.x
- Pygame

Install Pygame if you don't have it:

```bash
pip install pygame
```

---

## ▶️ How to Run

1. Clone or download this repository.
2. Navigate to the project directory.
3. Run the `tetris.py` file:

```bash
python tetris.py
```

4. Press any key to start the game!

---

## 🎮 Controls

| Key        | Action              |
|------------|---------------------|
| ⬅️ Left     | Move piece left     |
| ➡️ Right    | Move piece right    |
| ⬇️ Down     | Move piece down     |
| 🔼 Up       | Rotate piece        |
| ❌ ESC/Close| Exit game           |
